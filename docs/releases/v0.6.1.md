# MP14Tools 0.6.1

修掉 0.6.0 任务栏显示的两处问题：

- **「自动」位置改为居中**：0.6.0 把文字贴紧开始按钮左侧，右边只剩一条缝、左边空出
  一大截。现在在天气挂件与开始按钮之间的空档里居中（实测左右空隙基本相等）；
  空档放不下时才退回到贴紧开始按钮。
- **功耗显示**：这块电池的固件把放电速率报成**负数**（字段文档写的是无符号），
  0.6.0 把它当成离谱值过滤掉了，悬浮条只显示「电池」。现在按有符号解释、取绝对值：
  放电显示真实瓦数（如 `13.0W`）、充电显示 `+xx.xW`、插电显示 `AC`。
  电池卡片的「放电功率」同步恢复。

其余与 0.6.0 相同。
