# MP14Tools 0.8.1

降低被 Windows Defender 云端启发式误报（`Trojan:Win32/Sabsik.FL.A!ml`）的概率；功能与 0.8.0 相同。

- **应用程序清单**：可执行文件现在内嵌 manifest（`asInvoker`，不要求管理员权限；声明 Windows 10/11 兼容、
  PerMonitorV2 DPI 感知、长路径支持）。
- **完整的文件属性**：补全公司名（`CompanyName`）、版权（`LegalCopyright`）和文件说明。
- **不再使用 `-ExecutionPolicy Bypass`**：省电方案的辅助脚本改为 `powershell -File ... -ExecutionPolicy RemoteSigned`
  运行，脚本自己把输出写入日志（`-LogPath`），省电页的输出显示不变；省电计划任务与 MSI 的安装后动作同样改用 `RemoteSigned`。
  脚本的 `-DisableTurbo` / `-MaxPcieAspm` / `-WifiMaxSaving` / `-PowerModeEco` 现在接受 `1` / `0`。
- **保留符号表**：发布版 `strip = "debuginfo"`（体积略增）。

> 程序仍未做代码签名，新文件信誉为零，Defender 仍可能误报。如遇到，请在核对 SHA256 与 Release 页一致后，
> 向 Microsoft 提交误报（https://www.microsoft.com/wdsi/filesubmission）。
