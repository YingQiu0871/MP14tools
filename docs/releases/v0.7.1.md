# MP14Tools 0.7.1

## 任务栏悬浮条

- **开始菜单 / 小组件打开时主动隐藏、关闭后立刻恢复。** 这是 Windows 自身的行为：这类
  界面打开时，系统会停止合成任务栏左侧区域（悬浮条所在位置）的普通顶层窗口——实测连
  一个独立的最小测试窗口也会被压掉，不是本程序能绕开的。现在把它做成确定性行为：
  菜单一打开就主动藏起来（日志可见），关闭后立即回到原位，不再出现「还显示着但内容
  已经空了」的中间状态。
- 新增**垂直微调**（设置 → 通用 → 任务栏显示），和已有的水平微调一样即时生效。
- 修复一个渲染隐患：绘制后先 `GdiFlush` 再读位图，避免 GDI 批处理的时序问题。

## 关于控制台窗口

发布版（本 Release 的 `mp14tools.exe`）**没有控制台窗口**——只有开发用的 debug 构建
才会带。安装脚本安装的就是发布版，开机自启也会指向它。
