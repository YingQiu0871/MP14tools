# MP14Tools 0.5.0

界面改版：「显示」与「省电」合并成一页，整体换成卡片式排版。

## 合并后的「显示与省电」页

- **自动档位切换**：总开关 + 三档（插电 / 电池 / 节电模式）的可视化编辑——
  每档直接选刷新率（不动 / 60 Hz / 120 Hz）、HDR（不动 / 开 / 关）以及是否包含外屏；
  「切换依据」（节电模式开关 / 插拔电源）也在同一张卡片里。
- **当前显示器**：内屏/外屏、分辨率、刷新率与 HDR 状态，「刷新列表」和
  「按当前电源状态执行一次」照旧可用。
- **Windows 省电设置**：处理器上限、亮度档位、关屏时间、节电模式阈值与三个省电开关，
  以及「应用省电设置 / 撤销」按钮、辅助脚本状态和最近一次写入输出。
- **高级：内置电池显示策略**：原版逻辑折叠收起（默认关闭），需要时再展开。

## 排版与观感

- 全局卡片式分组：圆角、细边框、统一内边距；页面标题配一句话说明。
- 侧边栏导航改为整行、左对齐的 Windows 11 风格高亮。
- 滑块、勾选框与下拉框统一尺寸和配色；勾选框有清晰边框与勾选符号。
- 深色与浅色主题都做了适配。

## 兼容性

- 配置文件与 0.4.x 完全兼容，无需改动；省电页与档位开关的行为不变。
- 其余页面（触摸板、OEM 按键、日志、通用）只换了统一的卡片外观和标题样式。
