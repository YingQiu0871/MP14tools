# MP14Tools 0.3.0

为 Xiaomi Book Pro 14 2026（以及任何能报告电源/节电状态的 Windows 机器）加入**按状态切换的显示档位**：

- **插电时**：内置屏 120 Hz、HDR 打开
- **拔电但没开节电模式**：60 Hz、HDR 关闭
- **打开"节电模式"时**：60 Hz、HDR 关闭，并可选执行一条命令（用来切换到预建的省电电源方案）

原版只能"电池时降到目标档 + 提示关 HDR"，本版补上了它做不到的三件事：
HDR 能重新打开、插电有独立档位、以"节电模式"开关作为触发条件。

## 配置（`%LOCALAPPDATA%\MP14Tools\config.json`，保存即生效）

`profiles.enabled` **默认为 `true`**：启动后会立刻按当前状态套一次档位（插电即 120 Hz + HDR 开）。
不想要这个行为就把 `enabled` 或 `high.hdr` 改成 `false`。

```jsonc
"profiles": {
  "enabled": true,
  "mode": "battery_saver",     // battery_saver（默认）| ac_dc
  "high_only_on_ac": true,     // 防止"拔电但节电未开"时跑 120Hz + HDR
  "poll_ms": 2000,
  "high":   { "refresh": 120, "hdr": true,  "external": false, "command": "" },
  "medium": { "refresh": 60,  "hdr": false, "external": false, "command": "" },
  "eco": {
    "refresh": 60,
    "hdr": false,
    "external": false,
    "command": "schtasks /run /tn MP14Tools-EcoOn"
  }
}
```

- `mode`：`battery_saver` = 只有"节电模式"把机器切进 `eco`；`ac_dc` = 按插拔电切换。
- `refresh`：`60` / `120` / `0`（0 = 不动刷新率）。
- `command`：进入该档位时执行的命令，通过 `cmd /C` 运行、无控制台窗口；退出码会写进日志。
  **只在档位真的变化时执行**——避免"命令改了电源方案 → 电源方案又影响选档"的来回跳。
- `display.enabled` 保持 `false`（默认）。两个策略同时开会互相抢刷新率，日志里会写明。
- 把 `profiles.enabled` 改成 `false` 只是停止切换，当前屏幕档位会留在原处，不会自动恢复。

## 配套

- `tools/mp14-eco-setup.ps1`：一次性管理员脚本。建一个「MP14 省电」电源方案
  （电池下：处理器上限 50%、关闭睿频、PCIe ASPM 最大省电、亮度档位 40%、
  1 分钟关屏、无线网卡最高省电、节电阈值 40%），并创建两个"最高权限"计划任务
  `MP14Tools-EcoOn` / `MP14Tools-EcoOff`，供上面的 `command` 调用。`-Undo` 回滚。
- `tools/mp14-display-test.ps1`：只读诊断，确认内屏被报成 INTERNAL、当前刷新率、
  60/120 档位、HDR 支持与开关状态；`-Toggle` 可做一次往返测试。

## 实现

- 新增 `src/profiles.rs`：轮询 `GetSystemPowerStatus`，状态变化时才写显示；
  写失败会记日志并在 30 秒后重试一次，不会每 2 秒刷屏。
- `src/display.rs`：新增 `battery_saver_on()`（读 `SystemStatusFlag`）；HDR 相关代码与上游一致。
- `src/config.rs`：新增 `Profile` / `ProfileMode` / `ProfilesConfig` 与 `Config.profiles`。
- `src/main.rs`：`mod profiles;` + `profiles::spawn(...)`。
- 原有的电池策略与触摸板、热键、震动力度逻辑**未改动**。
