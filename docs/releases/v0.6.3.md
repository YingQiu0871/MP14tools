# MP14Tools 0.6.3

修掉 0.6.2 里截图时悬浮条的「一闪」：

- 0.6.2 靠每秒一次的轮询检测截图界面，截图界面约 0.2 秒就出现，而悬浮条最多要
  1 秒后才隐藏——这一小段里它还会出现在取景画面上，看起来就是闪一下。
- 现在挂了前台窗口变化事件钩子（`SetWinEventHook`）：截图界面一抢到前台，悬浮条
  **约 0.2 秒内**（与截图界面出现基本同步）就隐藏；取消/完成截图后同样即时恢复，
  位置不变。

实测：按下 PrtScn 后 ~200ms 悬浮条已隐藏（旧版 1.4s），ESC 后 ~100ms 恢复。

其余与 0.6.2 相同。
