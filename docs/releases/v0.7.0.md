# MP14Tools 0.7.0

新增「后台进程效率模式」——把不在前台的程序压进 Windows 11 效率模式（EcoQoS），
可以替代能源之星X 这类独立工具。

## 后台进程效率模式（新）

- **不在前台、且有窗口**的程序会被设为 Windows 11「效率模式」（与任务管理器里
  那个绿色树叶同一机制：降频、优先小核调度）；回到前台立即恢复。
- 只碰有可见窗口的进程；explorer、dwm、输入法、搜索等系统进程和 MP14Tools 自己
  永不节流；**忽略列表**（每行一个进程名，可省略 `.exe`）随时可加。
- 可选「只在电池供电时启用」。**免管理员权限**。
- 界面在「显示与省电」页，实时显示当前生效的进程数；关掉开关或退出程序时，
  所有被节流的进程都会恢复原样。
- 默认开启；不需要的话在卡片里取消勾选即可。

## 实测

- 记事本 / Chrome / Edge / Outlook 等后台窗口 → 节流；切回前台 → 恢复；
  再切走 → 再节流（往返三次全对）
- explorer、MP14Tools 自身、前台窗口全程保持正常调度
