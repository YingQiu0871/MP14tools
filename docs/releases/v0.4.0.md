# MP14Tools 0.4.0

界面把上一版放在 `config.json` 里的东西搬进了设置窗口：

- **显示页新增开关**：「开启省电模式时自动关闭 HDR」——勾上就是"节电模式打开时把内屏 HDR 关掉"，
  取消勾选则省电档不碰 HDR（对应配置里的 `profiles.eco.hdr = null`）。
- **新增「省电」页**：把电池供电时的那套电源设置做成滑条与勾选——
  最大处理器状态、显示器亮度档位、关屏时间、节电模式自动开启阈值，
  以及"关闭睿频加速 / PCIe 最大省电 / 无线网卡最高省电"三个开关。
  页面上有 **「应用省电设置」** 和 **「撤销（恢复原方案）」** 两个按钮，
  它们会以管理员身份调用辅助脚本 `mp14-eco-setup.ps1` 写入 Windows 电源方案
  （会弹一次 UAC；系统设为"从不通知"时静默完成），脚本输出显示在同一页下方。

改动细节：

- `src/config.rs`：新增 `eco_setup` 段（界面上的那些值都存这里）；`Profile.hdr` 由 `bool`
  改为 `Option<bool>`——`null` 表示"这一档不动 HDR"，旧配置里的 `true/false` 照常解析。
- `src/profiles.rs`：按 `Option<bool>` 处理 HDR，`null` 时跳过。
- `src/ui.rs`：新增「省电」导航页与显示页的 HDR 开关；`run_eco_script()` 用
  `ShellExecuteW("runas", …)` 调起提权脚本，输出重定向到 `%LOCALAPPDATA%\MP14Tools\eco-apply.log`。
- `tools/mp14-eco-setup.ps1`：新增 `-DisableTurbo` / `-MaxPcieAspm` / `-WifiMaxSaving` 三个开关；
  创建计划任务时**显式允许在电池下启动**（上一版用了默认设置，任务在电池上会被拒绝运行）；
  去掉这台机器不接受的 USB 选择性暂停项；原生命令统一走 `Invoke-Native`
  （避免 `2>&1` + `ErrorActionPreference=Stop` 把脚本打断）。
- 原有的电池策略、触摸板、热键、震动力度逻辑未改动。
