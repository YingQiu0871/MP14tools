# MP14Tools 0.8.2

修复：点开开始菜单（或搜索、小组件）时任务栏悬浮条会消失。

- **悬浮条改为任务栏的子窗口**：此前悬浮条是浮在任务栏上方的置顶窗口，Win11 打开开始菜单时会把任务栏提升到
  更高的系统层，普通置顶窗口被盖住，0.7.1 起因此改为“开始菜单打开时隐藏”。现在悬浮条作为 `Shell_TrayWnd` 的子窗口
  与任务栏一起合成（做法同 TrafficMonitor），开始菜单、搜索、小组件打开时保持可见，并去掉了上述隐藏逻辑。
- **Explorer 重启后自动恢复**：重启 `explorer.exe` 后几秒内悬浮条会自动重建，不需要重启本程序。
- **兜底**：如果在你的系统上无法创建子窗口，会自动退回旧的置顶窗口方式（此时开始菜单打开期间仍会隐藏）。
- 任务栏自动隐藏、全屏应用时，悬浮条随任务栏一起隐藏/滑动。

已知变化：子窗口不能使用“从屏幕截图中排除”，因此 PrintScreen 或录屏会拍到悬浮条；
截图工具（Win+Shift+S）的框选界面出现时悬浮条仍会自动隐藏。
