# MP14Tools 0.8.0

新增 **MSI 安装包**，并打磨了界面与文档：

- **MSI 安装包（新）**：发布页现在同时提供 `mp14tools-0.8.0-x64.msi`，按用户安装，
  无需管理员权限。可选功能：开机自启（`FeatAutostart`）、应用省电方案（`FeatEco`）。
  支持静默安装与卸载，升级安装不会重复运行省电方案，卸载会清理残留项；
  安装时若程序正在运行不会重复启动。
- **界面优化**：设置窗口的排版与细节打磨。
- **文档整理**：README 与项目文档重新梳理，补充了 `installer/` 结构说明。
- **测试与 CI**：新增配置模块单元测试，每次推送/PR 在 Windows 上自动构建并测试。

其余功能与 0.7.2 相同。
