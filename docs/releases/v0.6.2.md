# MP14Tools 0.6.2

任务栏悬浮条在截图时不再添乱：

- **截图 / 录屏拍不到它**：悬浮条被设置为「不参与屏幕捕获」
  （`WDA_EXCLUDEFROMCAPTURE`）——Win+PrtScn、截图工具、录屏软件里都不会出现，
  屏幕上照常显示。
- **截图取景界面出现时自动隐藏**：Windows 截图（Win+Shift+S）的取景覆盖层会把
  任务栏顶得重新排版，悬浮条以前会跟着跳位置、还会留在取景画面里。现在检测到
  截图覆盖层（`SnipOverlayRootWindow`）就立刻藏起来，取消或完成截图后回到原位。

其余与 0.6.1 相同。
