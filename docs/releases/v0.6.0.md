# MP14Tools 0.6.0

把「省电」往一个真正能用的电源工具推了一步，并加上任务栏实时显示。

## 任务栏显示（新）

- 在任务栏上显示 **CPU 占用 / 网速（↓下载 ↑上传）/ 功耗（电池放电 W、充电 +W、
  插电 AC）**，三个项目可以单独开关。
- **位置默认「自动」**：把文字放进天气挂件与开始按钮之间的空档、靠右排列，且绝
  不压到开始按钮；空档放不下时才改贴托盘。也可以在界面上固定选「天气挂件后」或
  「托盘左侧」。位置每次都从实时任务栏计算，图标增减不会跑偏。
- 文字颜色跟随任务栏深浅色自动变白/变黑；透明无背景、不抢焦点、不挡点击。
- 悬浮条每次刷新都会重新置顶——否则系统锁屏/解锁之后，任务栏会把它压在下面。
- 字号与水平微调在界面上调；刷新间隔在配置里（`taskbar.update_ms`，500–10000 毫秒）。

## 显示与省电页

- 新增 **电池卡片**：当前供电状态、电量、放电/充电功率、预计剩余时间、
  当前容量 / 满容量。
- 新增 **「省电体检」**：对照系统里实际存储的电源方案值逐项检查——包括
  `powercfg` 根本不显示的隐藏项（EPP、核心停放、散热策略……），每项显示 ✓ 或
  差在哪。
- 省电设置新增：
  - 处理器能效偏好（EPP，0–100，越高越省电）
  - 核心停放（开关 + 允许保持未停放的核心比例）
  - 电池下被动散热（先降频、再提速风扇）
  - 自适应亮度（需要环境光传感器）
  - 屏幕变暗 / 睡眠超时
  - 电池下电源模式 = 最佳能效（电源模式按 AC/DC 分开存储：接电时由省电档任务
    在电池上设置）
- **修掉"开关关掉后重新应用不生效"**：PowerSchemes 下的注册表键只给管理员读
  权限、写权限在 SYSTEM 手里，旧实现用 `Remove-ItemProperty` 清值是静默失败。
  现在改为写回原方案的值，并在脚本输出里如实说明结果。

## 辅助脚本

- `mp14-eco-task.ps1`（新）：计划任务脚本从「只切电源方案」升级为
  「切方案 + 在电池上把电源模式设为最佳能效 / 还原」。
- `mp14-eco-setup.ps1`：新增上述开关对应的参数；状态文件增加 pristine 记录
  （首次应用前的原值），`-Undo` 对多次应用过的机器更准确。
- `local/install-mp14tools.ps1`：把任务脚本复制到配置目录；计划任务引用的是该
  固定路径，而不是补丁目录。

## 兼容性

- 配置文件向后兼容；缺少 `taskbar` 段时按默认值补上（贴在托盘左侧、开启）。
- 旧版写入的残留值不受影响；在「显示与省电」页重新点一次「应用省电设置」，
  各项会按新逻辑对齐，再用「省电体检」可以逐项确认。
